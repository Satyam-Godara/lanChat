# ChatApp – Real-Time Messaging Application

A real-time chat application that enables instant communication between users using WebSockets. The project demonstrates backend event handling, live message broadcasting, and real-time client updates.

## 🚀 Features

* Real-time messaging using **WebSockets**
* Instant message broadcasting
* User session handling
* Responsive chat interface
* Lightweight backend architecture

## 🛠 Tech Stack

Frontend

* HTML
* CSS
* JavaScript

Backend

* Node.js
* Express.js
* WebSockets (Socket.io / ws)

## ⚙️ Installation

Clone the repository:

```
git clone https://github.com/satyamgodara/lanchat.git
cd chatapp
```

Install dependencies:

```
npm install
```

Run the server:

```
npm start
```

Open in browser:

```
http://localhost:3000
```
